# Welcome to scribemd

This is your collaborative markdown workspace. Your notes live in the
`notes/` directory as plain `.md` files, version-controlled by git.

## How collaboration with Claude works

1. **You** run the webapp locally (`npm run dev`) and edit notes in the browser.
2. **Claude** clones this same repo elsewhere, edits notes, and pushes commits.
3. You click **Pull** in the top bar to fetch Claude's changes and see them
   instantly in the sidebar.
4. After editing, type a commit message, click **Commit**, then **Push**.

## Tips

- Press `⌘S` / `Ctrl+S` to save the current file.
- Use folders (`ideas/today.md`) to organize — the sidebar shows the full path.
- The right pane renders a live preview with GitHub-flavored markdown.

Delete this file when you're ready to start fresh.
